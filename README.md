# CodeAlpha Internship Tasks

This repository contains the projects completed as part of my **CodeAlpha Internship**.

The repository includes two full-stack web development tasks:

* **Task 1 – URL Shortener**
* **Task 2 – Event Registration System**

## 📌 Task 1 – URL Shortener

A web-based URL Shortener that allows users to convert long URLs into shorter, shareable links.

### Features

* Shorten long URLs
* Generate short URLs
* Redirect users from short URLs to the original URL
* Store URL data using a database
* Simple and responsive web interface

### Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* SQLite

### Project Folder

`Task-1/CodeAlpha_URLShortener/`

---

## 📌 Task 2 – Event Registration System

A web-based Event Registration System that allows users to explore upcoming events and register for available events.

### Features

* View upcoming events
* View event date, location, capacity and available seats
* Register for an event
* Prevent duplicate registration using the same email
* View registrations using an email address
* Cancel a registration when required

### Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* SQLite

### Project Folder

`Task-2/CodeAlpha_EventRegistration/`
